## Conventions

- Tooling: Mermaid (`.mmd`) for flows · TikZ (`.tex`) for publication figures ·
  matplotlib/seaborn (`.py`, run with `../../../.venv/bin/python` from this folder) for data plots.
- Output: vector PDF/SVG preferred; raster ≥ 300 dpi.
- Naming: `figNN_<short-name>.<ext>` (same stem for source and rendered).
- Colour-blind-safe palette, legible in greyscale, labels readable at printed column width
  (IEEE single column ≈ 3.5 in / 88 mm; double column ≈ 7.16 in / 182 mm).
- Terms must match GLOSSARY.md. Every figure is referenced in the text before it appears.
- No decorative diagrams.
