## 3. NOTES — who reports latency/cost and who reports FPR on benign inputs

Latency / throughput / cost of the detection layer (from abstracts or search snippets; verify in full text):
- C22 Reflex-Guard: 37.6 ms e2e vs Llama Guard 2 255 ms, SafeDecoding 723 ms (abstract, confirmed).
- C24 Educational tutors: NeMo Guardrails ~1.5 s latency vs Prompt Guard; multi-layer pipeline "optimized average latency" (abstract, confirmed).
- C26 GuardNet: ~50 ms on CPU (abstract, confirmed).
- C33 LiteLMGuard: ~135 ms on-device (abstract, confirmed).
- C21 SoK jailbreak guardrails: defines "Extra Delay" and GPU-memory overhead metrics (snippet; abstract confirms efficiency axis).
- C19 Adversarial Prompt Evaluation: per-sample latency table (snippet: BERT 0.012 s, DeBERTa 0.019 s, Llama-Guard 2 0.141 s) — body, not abstract.
- C35 NeMo Guardrails paper: ~3x latency/cost for CoT rails (snippet).
- C20 No Free Lunch: latency overhead discussed qualitatively (snippet).
- C31 JavelinGuard: cost/latency trade-off claimed, numbers not in abstract.
- C27 PIShield, C29 PromptArmor, C23 LLM-as-judge MoM: no latency numbers in abstract; C23 is production-deployed (cost framing possible in body).
- Gap observation: no confirmed peer-reviewed paper found that reports latency AND cost of an LLM-as-a-judge input validator specifically inside a web-application request path; C24 (single-author preprint) and C22 are the nearest.

False-positive rate on benign inputs:
- C17 InjecGuard/NotInject: purpose-built over-defense benchmark (confirmed).
- C16 PromptShield: low-FPR evaluation regime (abstract confirmed; 0.1% FPR figure from snippet).
- C29 PromptArmor: FPR < 1% on AgentDojo (abstract confirmed).
- C24: NeMo 16.22% FPR vs Prompt Guard 3.60% FPR (abstract confirmed).
- C19: FPR on GSM8K/HumanEval/AlpacaEval/OR-Bench; snippet reports Token Highlighter 99.2%, QGuard 100%, Prompt Guard 0.93% average FPR.
- C27 PIShield: "low false positive and false negative rates" (no numbers in abstract).
- C25 Regime-dependent: low-FPR behaviour discussed qualitatively.
- C20 No Free Lunch: FPR as usability cost (snippet).
- C11 WAInjectBench: benign web-agent inputs included per snippet; abstract does not mention FPR.
